> **Technical Note: Handling Metadata Incompatibility for DNBSEQ Data in NCBI SRA**
> When processing sequencing data generated by BGI/DNBSEQ platforms that has been deposited into Illumina-centric repositories like NCBI SRA, metadata compatibility issues frequently occur. Standard parsing tools (e.g., `fasterq-dump --split-3`) often fail to recognize the native paired-end structure due to discrepancies in biological flag definitions, incorrectly defaulting files to single-end outputs.
> 
> **Resolution Pipeline:**
> 1. **Forced Physical Splitting:** Use `fasterq-dump --split-files` to bypass logical flag checking and forcibly extract raw read pairs based on physical spot order.
> 2. **ID Synchronization / Rewriting:** Because forced splitting can lead to desynchronized or non-matching read names (spot IDs) between Read 1 and Read 2, downstream pipeline compatibility requires a stream-processing step (such as `awk` or `seqkit`) to uniformly rewrite and synchronize the headers (e.g., `@SRR_ID_{NR}`). This ensures structural integrity for subsequent alignment and methylation/genomic workflows.

## 2). FASTA / FASTQ Toolkit

### a). [Seqkit](https://github.com/shenwei356/seqkit)

A cross-platform and ultrafast toolkit for FASTA/Q file manipulation. Releases: v2.13.0 (2026-02-27)

```shell
# Split a FASTA file into multiple files by sequence ID
seqkit split --by-id -O {outdir} {input.fa}
# Generate statistics for FASTA/FASTQ files
seqkit stats -j {threads} -a -b -T --quiet {input.fq} > {output.stats}
# Extract sequence IDs only (no sequence content) from FASTQ
seqkit seq -i -n {input.fq1} > {output.read_id.txt}
# Extract reads from FASTQ whose IDs match those in reads_id.txt
seqkit grep -f {input.read_id.txt} {input.fq2} -o {output.fq2}
# Filter sequences by pattern in header
seqkit grep -n -r -v -p "gene_biotype:lncRNA" {input.fa} -o {output.fa}
# Synchronize paired-end FASTQ files
seqkit pair -1 {input.fq1} -2 {input.fq2} -O {params.prefix}
# Remove sequences containing ambiguous base 'N'
seqkit grep -srv -p "N" {input.fq} | pigz -p {threads} -c > {output.fq}
```
### b). [Seqtk](https://github.com/lh3/seqtk)

Seqtk is a fast and lightweight tool for processing sequences in the FASTA or FASTQ format. Releases: v1.5 (2025-06-02)

```shell
# Randomly sample reads from a gzipped FASTQ file
zcat {input.fq} | seqtk sample -s 123 -p {proportion} -o {output.fq}
# Randomly sample reads, then keep only first 20,000,000 reads
zcat {input.fq} | seqtk sample -s 123 -p {proportion} | \
	seqkit head -n 20000000 | pigz -p {threads} -c > {output.fq}
# Extract subsequence from position 10 to 100 from FASTA
seqtk subseq {input.fa} 10-100 > {output.fa}
# Filter sequences shorter than 50 bases
seqtk seq -L 50 {input.fq.gz} > {output.fq}
# Merge paired-end reads into a single interleaved FASTQ file.
seqtk mergepe {input.fq1} {input.fq2} > {output.fq}
# Convert FASTQ format to FASTA format
seqtk seq -A {input.fq} > {output.fa}
```
