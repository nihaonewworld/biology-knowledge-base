# Biology Knowledge Base

A personal collection of biology and bioinformatics notes, experimental resources, computational workflows, and public data analyses. Content is continually updated and varies in completeness.

## Repository Structure

| Directory | Purpose |
| :--- | :--- |
| `01_Biology` | Biology fundamentals, with reference to textbooks and research papers. |
| [02_Bioinformatics](02_Bioinformatics/) | Bioinformatics concepts, technologies, and methods. |
| [03_Computing](03_Computing/) | Computer science concepts and computing tools. |
| [04_Protocols](04_Protocols/) | Experimental protocols and reference resources. |
| [05_Pipelines](05_Pipelines/) | Computational workflows, scripts, and environments. |
| [06_Analyses](06_Analyses/) | Public data analyses and supporting code. |
| `07_Projects` | Research projects and supporting code. |
| [99_Assets](99_Assets/) | Images and supporting assets. |

## Reading and Running

Read notes in a Markdown editor and open notebooks in [Jupyter](https://jupyter.org/), [VS Code](https://code.visualstudio.com/), or another compatible editor. Before running code, review its requirements and adapt the environment, inputs, paths, and parameters to your own setup. Further testing and validation may be needed for your data and environment.

Many completed notebooks include saved outputs and figures, which account for much of the repository size. Preserve the relative directory structure when reading notes so that local image links continue to work.

Most notebooks have been rerun and tested using [R](https://www.r-project.org/) v4.5.2, [Bioconductor](https://bioconductor.org/) v3.22 or [Python](https://www.python.org/) v3.12, as appropriate.
